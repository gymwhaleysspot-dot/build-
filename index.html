How this works

The page commits the selected source to a unique path under src/web-builds/. That push starts GitHub Actions. Ubuntu installs the real luac5.3, compiles with -s, runs the recursive MT12 normalizer, validates the bytecode header and size, creates a SHA-256 manifest, then returns a ZIP artifact.

Deploy only the normalized .luac inside the ZIP. Do not deploy the source or raw desktop bytecode.
